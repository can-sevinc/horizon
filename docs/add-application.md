# {% include icon.html name="save" %} Add an application
{: #add-an-application }

Use the bookmark for a job post. For a message from a recruiter, you can use the bookmark or open the form yourself.

## From a job post

1. Open the job post and click the bookmark. It supports [these sites](supported-sites.md) and tries to read other sites too.
2. A new issue form opens with the company, position, date, link, and job description.
3. Check the values. If a value came from the link, Github can reset it when you edit the form. Fix it in the issue after you create it instead.
4. Check **Job description**. If you selected text on the page, the bookmark uses that text. If the description is too long for the link, it is shortened and the full text is copied to your clipboard. Paste the rest into the issue later.
5. Click **Create**.

**Stage** can stay empty. It becomes **Applied**. **Source** is read from the link: **LinkedIn job post**, **Job board**, or **Company website**. Without a link, it becomes **Recruiter outreach**. Choose **Referral** or **Other** yourself. A value you choose is kept.

If the job description is empty, a comment and the weekly summary remind you. Save it while the post is still online.

---

## {% include icon.html name="contact" %} From a recruiter message
{: #from-a-recruiter-message }

On a computer, open the recruiter's LinkedIn profile and click the bookmark. It fills **Recruiter / contact**. Add the company and position, then paste the message into **Job description / recruiter message**.

On a phone, open the new application form from your copy's README. Paste the message there. **Job link** can stay empty if you do not have one.

## Save a job for later

Choose **Wishlist (not applied yet)** in **Stage**. When you apply, comment `/applied` on the issue. You do not need to create another issue.

---

## The same job twice

If another issue has the same job link, Horizon adds a comment with its number. Check both before deleting anything. Sometimes it is a duplicate; sometimes you are applying again.
